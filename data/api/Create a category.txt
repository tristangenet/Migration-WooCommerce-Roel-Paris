POST - /v3/shops/:shopId/categories

Parameter
Field	Type	Description
id_parent	Integer	
The id parent category, 0 if it's a parent category

name	String	
The category Name

url	String	
The url category

menu_title	String	
The title's menu

visible	Boolean	
Set visibility

meta.title	string	
Meta Title, set to null if you want to use default meta title generated by WiziShop

meta.description	string	
Meta Description, set to null if you want to use default meta description generated by WiziShop


JSON ATTENDU : 

{
    "id_parent": 0,
    "name": "My new category name",
    "url": "category-new",
    "menu_title": "Menu title",
    "visible": true,
    "meta": {
        "title": "title",
        "description": "meta description"
    }
}
